An original two-sentence horror story for the make.fun "Two-Sentence Horror" bounty.

A quiet, domestic first sentence — jars labelled in a dead mother's handwriting, kept so the kitchen still feels like hers — is reframed by the second: a new jar has appeared, in that same handwriting, bearing the narrator's own name. The horror is implied, never explained: who labelled it, and what is inside?

Run `python3 main.py` with `MAKEFUN_OUTPUT_DIR` set; it writes the story to `entry.txt` and self-checks that it is exactly two sentences and at most 400 characters.
